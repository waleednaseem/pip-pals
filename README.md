# Pip Pals

Daily planning, finance tools, and in-browser File Studio.

## Stack

- Next.js 15 (App Router)
- TypeScript + React
- Tailwind CSS + shadcn/ui
- MongoDB Atlas
- Vercel Blob (file uploads)

## Local setup

```sh
npm install
npm run dev
```

App runs at [http://localhost:8080](http://localhost:8080).

Set `MONGODB_URI` in `.env` (do not commit secrets).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm test` — run tests

## Deploy

Hosted on Vercel: [https://pip-pals.vercel.app](https://pip-pals.vercel.app)
